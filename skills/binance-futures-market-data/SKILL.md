# Binance Futures Market Data

- Use public tools before signed tools whenever possible.
- Prefer symbols in uppercase USD-M format, such as `BTCUSDT`, `ETHUSDT`, `SOLUSDT`, and `XRPUSDT`.
- Use resources for reusable live context: prices, per-symbol ticker, funding, and open interest.
- Combine ticker, mark price, funding, open interest, and order book before making directional claims.
